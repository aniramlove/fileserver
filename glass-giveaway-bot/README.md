# Glass Giveaway Bot\n\nTelegram Mini App starter: React + TypeScript + Vite, Telegram Serverless backend and SQLite. This is a development scaffold, not a production-ready giveaway platform.\n\n## Included\n- Liquid Glass UI with Telegram light/dark theme adaptation.\n- Giveaway listing and participation flow.\n- Server-side CAPTCHA challenge, expiry and per-giveaway pass record.\n- Server-side membership checks via Telegram Bot API.\n- Referral startapp links and extra ticket accounting.\n- Boost-based ticket calculation.\n- Admin-only giveaway creation endpoint.\n- GitHub Actions hourly scheduler for start/end posts and weighted winner draw.\n\n## Setup\n1. Use Node.js 18+ and run npm install, then npm run dev.\n2. Enable Serverless for your existing bot in @BotFather. Run npx tgcloud login and authenticate with the Serverless CLI Access token from @BotFather. This is not the Bot API token.\n3. Add your numeric Telegram user ID to tgcloud/lib/config.js.\n4. Build and deploy with npm run deploy; apply DB migrations with npx tgcloud migrate.\n5. Set the deployed Mini App URL in @BotFather.\n6. Add the bot as administrator to every required channel/group. Verify getChatMember and getUserChatBoosts permissions on a test channel.\n7. Add GitHub Actions secret TGCLOUD_TOKEN and enable Actions.\n\n## Important\n- Serverless endpoint SDK details and CLI flags can vary by installed CLI release. Verify against the current Telegram Serverless docs/CLI help before production deployment.\n- GitHub cron runs hourly and can be delayed; it is not exact-to-the-second scheduling.\n- Admin IDs, Bot API credentials and other secrets must never be committed.\n- Add monitoring, retries, concurrency-safe entry writes, audited draw records and production tests before public launch.\n
